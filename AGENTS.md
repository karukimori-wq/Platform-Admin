# Platform Admin Agent Instructions

Before substantial monitoring, ingestion, observability, deployment, cross-app integration, or production-readiness work, consult `karukimori-wq/ai-development-intelligence`.

Follow `core/autonomous-development-policy.md`: continue through multiple executable monitoring/integration tasks, verification, fixes, related checks and documentation rather than stopping after each small step. Ask only at a defined stop condition; continue independent authorized work first when possible.

Use the task retrieval protocol, ranking/index, and `memory/platform-admin/`. For substantial tasks, follow `core/task-run-standard.md` and `core/operational-learning-loop.md`. Verify current app endpoints/contracts before applying remembered guidance and use strict failure-outcome attribution.

Current Platform Admin code is authoritative for implementation. `professional-platform-contracts` is authoritative for formal contracts. Development intelligence is advisory and must not become a product source of truth.

After meaningful work, evaluate extraction and capture only reusable failures, decisions, patterns, contradictions, or stable evidence. Prefer updating existing knowledge over duplicates.

Store operational lessons, not secret values, tokens, credentials, raw sensitive logs, or personal data.
